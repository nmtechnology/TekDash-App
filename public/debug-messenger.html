Testing the Messenger Component

Quick Instructions

There are two ways to load test notes in the Messenger component:

  1. URL Parameter Method: Add ?demo=true to the URL of any page that includes the Messenger component.
    https://yourapp.test/work-orders/123?demo=true
  2. Console Method: Open your browser's developer console and call the following function:
    // Find the Vue component instance for the Messenger const messengerComponent = document.querySelector('.messenger').__vue__;
    // If that doesn't work, try this: // const messengerComponent = document.querySelector('.messenger').__vueParentComponent.ctx;
    // Call the test notes function messengerComponent.addTestNotes();
Note: The test notes are for visual testing only and will not persist in your database. They are added locally in the component's state.

Test Notes Details

The test notes include:

  • Messages from different user roles (admin, technician, customer)
  • Regular and urgent messages (urgent messages should appear in red)
  • Messages with timestamps ranging from 3 days ago to 1 hour ago

This helps verify that:

  • Message bubbles are colored correctly based on sender
  • Urgent messages are styled correctly with the red color and warning icon
  • User avatars show correct initials
  • Messages appear in chronological order
